# ERRC 그리드 — kids-economy

작성일: 2026-09-17 · 단계: S1 · 기준 산업: 아동 용돈·금융 교육 앱 (퍼핀 · 아이부자 · 토스 유스 · 용돈기입장류)
프로젝트 규칙: **Eliminate·Reduce는 CPU_월과 운영 부하를 깎는 축으로 먼저 본다.**

---

## 업계가 당연하게 여기는 것들

경쟁 제품이 공통으로 갖춘 요소를 나열하면 이렇다 — 선불카드 발급, 잔액 하나, 조르기·자동충전, 금융 퀴즈와 레벨, 보상 포인트, 주식 체험, 캐릭터 월드, 사용내역 실시간 알림, 부모 대시보드.

이 목록에서 **학습에 필요한 것**과 **부모의 불편을 줄이는 것**을 갈라야 한다. 둘은 자주 반대 방향이다.

---

## Eliminate — 없앤다

| 없앨 것 | 왜 | 무엇이 절감되나 |
|---|---|---|
| **조르기 / 용돈 추가 요청** | 예산 제약 자체를 지운다. 희소성 `4사07-01`이 없으면 선택도 우선순위도 배울 자리가 없다 | 부모 알림·승인 플로우 전체 |
| **자동 충전** | 잔액이 0에 닿는 경험을 없앤다 | 금융 연동 |
| **퀴즈 보상 (풀면 돈)** | 돈을 '수행의 대가'로 만든다. 집안일 연동 용돈과 구조가 같고, 그 집단은 저축률이 낮았다 | 콘텐츠 제작비, 보상 정산 |
| **금융 퀴즈·레벨·수료증** | 지식 +0.25 SD / 행동 +0.05 SD. 측정하기 쉬워 목표가 되기 쉽고 그래서 위험하다 | **CPU 대폭**: 2,000문항급 콘텐츠 제작·운영 |
| **선불카드 발급** | 저학년은 현금이 맞고, 토스 유스가 만 7세부터 이미 표준이다 | **인허가·정산·분쟁 전부.** 조건 ③·④가 여기서 살아난다 |
| **주식 체험·주가 예측** | EU/OECD 6~10세 역량에 `(104)` 한 줄뿐. 투기적 판단을 훈련시킨다 | 시세 API, 규제 리스크 |
| **또래 랭킹·비교** | 소비가 사회적 비교에 붙으면 `(47)` 필요와 욕구 구분이 무너진다 | 소셜 기능 전체 |

## Reduce — 줄인다

| 줄일 것 | 어디까지 | 이유 |
|---|---|---|
| **아이 화면** | 지갑 상태를 **보는 것**까지만 | 6~9세는 앱을 운영하지 않는다. 입력은 부모가 한다 |
| **캐릭터·게임 월드** | 지갑 두 칸을 알아보게 하는 최소 시각 요소만 | 재미는 지속을 사지 학습을 사지 않는다(E3). 제작비는 CPU가 아니라 초기 공수를 먹는다 |
| **실시간 알림** | 주 1회 배분일 + 주말 돌아보기, 둘뿐 | 현금이라 실시간 이벤트가 없다. 알림이 잦으면 부모가 끈다 |
| **기록 항목** | 금액·이름·칸 세 가지 | 입력이 5분을 넘으면 A1(부모 지속)이 깨진다. **이 제품에서 입력 시간은 곧 이탈률이다** |
| **생성형 모델 호출** | 월 1회 요약 배치만. 나머지는 규칙 기반 | Kill Rule 2. 결제·이벤트마다 호출하면 적색 |

## Raise — 올린다

| 올릴 것 | 업계 수준 | 우리 수준 |
|---|---|---|
| **제약의 강도** | 모자라면 채워준다 | **모자란 상태를 유지한다.** 이것이 교재다 |
| **부모 대화의 구조화** | 사용내역을 보여주고 끝 | 질문을 **하나로 정해서** 준다. 무엇을 물을지 모르는 게 부모의 실제 장벽 |
| **개입 빈도** | 월 단위 결산 | **주 단위.** 저학년 67%가 주 단위로 받는다. 메타회귀상 강도가 효과를 만든다 |
| **행동 지표의 지위** | 퀴즈 점수·레벨 | **대기 후 취소율·주간 배분 실행률**을 제품 전면에. 부모에게 보고하는 숫자 자체를 바꾼다 |

## Create — 새로 만든다

| 만들 것 | 업계에 없는 이유 | 이것이 만드는 것 |
|---|---|---|
| **사기 전 멈춤 (하루 자고 정하기)** | 결제를 늦추는 기능은 핀테크의 KPI와 정면 충돌한다. 공공은 콘텐츠만 만든다 | 부모 고민 1위(충동구매 41.2%)에 대한 유일한 직접 대응 |
| **취소 직후 저축을 한 번 더 묻는 구조** | 안 산 돈을 목표로 옮길지 아이가 그 자리에서 고른다. 자동으로 옮기지 않는다 | 참는 것과 모으는 것이 **각각 다른 결정**으로 남는다. 아이가 저축이라는 행위를 실제로 해본다 |
| **칸 나누기 도안의 무료 표준화** | 실물 제조사는 물건을 팔아야 하므로 도안을 풀 수 없다 | 진입 장벽 0. S1 실행률이 곧 이 제품의 첫 관문 |
| **주말 5분 대화 대본** | 앱은 보통 부모를 '관리자'로 놓지 '대화 상대'로 놓지 않는다 | 효과가 확인된 유일한 조건을 제품 안에 넣는 것 |

## 가치 곡선 요약

낮춘 축이 **전부 원가·운영 부하와 같은 방향**이다 — 카드·퀴즈·캐릭터·실시간을 버리면서 인허가, 콘텐츠 제작비, 정산, 분쟁, 모델 호출이 함께 빠진다. 올린 축(제약·대화·빈도·행동지표)은 **소프트웨어 원가가 거의 붙지 않는 것들**이다.

> 이 그리드가 성립하는 이유는 하나다. **업계가 올려놓은 축들이 대부분 학습을 돕는 게 아니라 학습의 조건을 지우고 있었다.** 그래서 낮추는 것이 곧 제품을 좋게 만든다.
