# 확장 계획 — kids-economy

작성일: 2026-09-22 · 단계: S4
전제: 이 모델의 합격선은 이익이 아니라 **유지 배수 1.0 · 1인 운영**이다. 투자는 필수가 아니라 선택이다.

---

## 1. 투자가 들어오면 풀리는 것

| 풀리는 것 | 왜 돈으로 풀리나 | 필요 규모 |
|---|---|---|
| **채널 (A6)** | 유기적 획득의 한계가 이 아이디어의 최대 병목이다. 유료 획득이 가능해지면 **10만이 산술에서 계획이 된다** | CAC $5 가정 시 10만 명 = **$50만** `[Assumption]` |
| 해외 동시 출시 | 번역·현지화·스토어 대응·시차 CS를 사람으로 메운다 | 인건비 |
| 인프라 선결제 | 약정으로 CPU를 더 낮춘다 | 소액 |

## 2. 돈으로 **안** 풀리는 것

| 병목 | 왜 |
|---|---|
| **A2′ — 제3자 단서가 작동하는가** | 제품이 실제로 아이를 움직이는지는 자본과 무관하다. **틀렸으면 돈을 써서 더 많은 사람에게 안 통하는 제품을 배포하는 것뿐** |
| **A1 — 부모가 지속하는가** | 리텐션은 마케팅으로 못 산다 |
| 조건 3 (1인 운영) | **사람을 뽑아 운영하는 것은 이 모델에서 확장 사유가 될 수 없다.** 조건 3 위반이다 |

> **순서가 있다.** A1·A2′가 서기 전의 투자는 실패를 크게 만들 뿐이다. 투자 논의는 **POC 실측 이후**다.

## 3. 투자 없이 가는 경로 (기본값)

```
크레딧 1~2년  →  무료로 사용자 축적  →  유료 235명  →  유지 배수 1.0  →  자립
```

이 경로의 제약은 **속도**다. 유기적 성장 중앙값(일 0.3%)으로는 3년에 26배이므로, 초기 시드 1만 명이 있어야 26만에 닿는다.
**실험 2가 그 시드의 가능성을 재는 첫 측정이다.**

## 4. 투자를 받는다면 — 무엇을 증명한 뒤인가

| 시점 | 증명해야 할 것 |
|---|---|
| POC 종료 | A1(W4 리텐션) · A2′(아이 반응) · A3′(주 2회+ 사용) |
| 유료 출시 후 | A7(실제 결제 전환) · 재구독률 |
| **그 뒤에** | 채널 투자. **"돈을 넣으면 사용자가 는다"는 것을 소액으로 먼저 증명한 뒤** |
