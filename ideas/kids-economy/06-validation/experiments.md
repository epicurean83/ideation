## 실험 1 — 종이로 하는 보여주기 (2주 준비 + 4주 관찰)

**검증:** A1 · A2′ · A3′ · A4 · A5 → [poc-scope.md Phase 0](../04-product/poc-scope.md)

| | |
|---|---|
| 방법 | 10~15가구에 **목표 카드(색칠형)·금액→주 계산표·지갑 도안·기록지** 배포. 운영자가 메신저로 주간 루프 운영. **앱 없음** |
| 비용 | 인쇄비 + 운영자 시간 주 2시간 × 6주 |
| **성공 기준** | 4주 지속률 **≥50%** · 보여주기 **주 2회 이상 가구가 절반 이상** · 지갑 준비율 **≥60%** |
| **실패 기준** | 4주 지속률 **<30%** → **종료** · 보여주기 **주 1회 미만** → 설계 재검토 |
| 함께 관측 | 아이가 화면을 보고 생각을 바꾼 사례(A2′, 정성) · 목표 카드를 아이가 스스로 색칠하는가(A4) · 보여준 뒤 사기로 한 비율(A5) |

## 실험 2 — 채널 탐침 (2주) ★ 가장 먼저

**검증:** A6 — **지금까지 한 번도 실측하지 않은 축**

| | |
|---|---|
| 방법 | 한 장짜리 랜딩 + 대기자 명단. **채널 네 개에 각각 같은 문구를 올린다** — 맘카페 · 육아 커뮤니티 · 인스타 육아 계정 · 지인 소개. **도안 PDF를 무료 미끼로** 건다 |
| 측정 | 채널별 **노출 → 방문 → 명단 등록** 전환율, 등록당 소요 시간 |
| 비용 | 광고비 0. 랜딩 제작 2일 |
| **성공 기준** | 2주 안에 **대기자 100명** · 그중 **한 채널이 50% 이상**을 가져옴 (= 되풀이할 경로가 있다) |
| **실패 기준** | 대기자 **30명 미만** → 채널 가설을 다시 세운다. 여기서 안 되면 10만은 산술이 아니라 환상이다 |

> **실험 1보다 먼저 돌린다.** 실험 1의 참가 가구를 모으는 일이 곧 실험 2이기도 하다. 두 실험이 같은 모집 활동을 공유한다.

## 실험 3 — 지불 의사 탐침 (1주, 실험 2에 얹는다)

**검증:** A7

| | |
|---|---|
| 방법 | 랜딩에 **가격 페이크 도어**. "월 3,000원 / 월 5,000원 / 무료로 쓰고 나중에 결정" 세 버튼. 누르면 "아직 준비 중입니다" |
| 측정 | 버튼별 클릭 분포. **무료 선택 비율이 핵심** |
| 비용 | 0 (실험 2에 포함) |
| **성공 기준** | 유료 버튼 클릭이 **전체의 15% 이상** |
| **실패 기준** | 유료 클릭 **5% 미만** → 국내 무료 지형 가설이 확인된 것. **해외 우선 전략으로 전환** |

## 우선순위 (RICE, Effort = 1인 주)

| 실험 | R | I | C | E | RICE |
|---|---:|---:|---:|---:|---:|
| **2. 채널 탐침** | 10 | 3.0 | 80% | 0.5 | **48.0** |
| **3. 지불 의사** | 7 | 2.0 | 80% | 0.2 | **56.0** |
| **1. 종이 보여주기** | 9 | 3.0 | 85% | 2.0 | **11.5** |

> 3번이 RICE 최상위인 것은 **공수가 거의 0**이기 때문이다. 2번에 얹혀 간다.
> **순서: 2 + 3 동시 → 1.** 채널이 안 서면 실험 1을 할 참가자도 못 모은다.

## 3개월 일정

```
1~2주   실험 2 + 3 (랜딩·대기자·가격 탐침)
3~4주   실험 1 준비 (키트 인쇄, 참가 가구 확정)
5~8주   실험 1 관찰 (4주)
9~10주  결과 정리 → G3 판정 → Phase 1 착수 여부
```

**세 실험 모두 개발 없이 돌아간다.** 12주 개발은 이 결과가 통과한 뒤의 일이다.
