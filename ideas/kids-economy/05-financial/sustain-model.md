## 2. 유지 배수 1.0 도달점 — 235명

**앱스토어 수수료를 빼고 계산한다.** 소규모 개발자 프로그램 기준 15%.

| 유료 전환 | 유료 사용자 | 연 매출 (수수료 차감 후) | 유지 배수 |
|---:|---:|---:|---:|
| **0.24%** | **235명** | **720만원** | **1.00** ← 손익분기 |
| 0.5% | 500명 | 1,530만원 | 2.13 |
| **1.0%** | **1,000명** | **3,060만원** | **4.25** |
| 2.0% | 2,000명 | 6,120만원 | 8.50 |
| 3.0% | 3,000명 | 9,180만원 | 12.75 |

> **10만 명 중 235명이 월 3,000원을 내면 서비스가 자립한다. 0.24%다.**
> 구독 앱의 통상 유료 전환율이 1~5%이므로, **하한의 4분의 1만 달성해도 선다.**

### 비교 사례

| 제품 | 단가 | 신뢰도 |
|---|---|---|
| Greenlight | $5.99~10.98/월 | High |
| Acorns Early (구 GoHenry US) | $8/월 | High |
| BusyKid | $4/월 | Medium-High |
| Rooster Money (비고객) | £1.99/월 | Medium |

**해외 부모는 아동 금융 앱에 월 $4~10을 실제로 낸다.** 우리 가정(월 3,000원 ≈ $2.2)은 그 절반 이하다.
**국내는 지불 사례가 없다** — 이것이 [global-feasibility.md](../01-discovery/global-feasibility.md)에서 짚은 국내·해외 트레이드오프다.

## 3. 수단 세 개 — 우선순위대로

CLAUDE.md의 "원가를 0에 가깝게 → 크레딧 → 소수 유료 → 스폰서 → 광고" 순서를 따른다.

### 수단 0. 원가를 깎는다 (가장 싼 수입은 쓰지 않은 돈)

이미 적용한 것들이다.

| 결정 | 절감 |
|---|---|
| 카드 미발급 | 결제 연동·정산·분쟁 전부 |
| 생성형 모델 호출 없음 (규칙 기반) | 100만 기준 월 210만원 |
| **사진 기기 내 저장** | 스토리지 + 모더레이션 |
| 화면 4~5개 | 개발·운영 |

### 수단 1. 클라우드 크레딧 — 초기 1~2년

| 항목 | 값 |
|---|---|
| 필요액 | 연 720만원 ≈ **$5,000** |
| 후보 | AWS Activate · Google for Startups · Cloudflare 스타트업 프로그램 `[검증 필요]` |
| 기대 | $1,000~5,000 / 1~2년 |
| **소진일** | **POC 종료 + 12~24개월. 캘린더에 박아둔다** |

> **크레딧은 수입이 아니라 유예다.** 소진일 6개월 전에 수단 2가 서 있지 않으면 그때가 종료 시점이다.

### 수단 2. 앱스토어 인앱 구독 — 주력

| 항목 | 값 |
|---|---|
| 단가 | 월 3,000원 (또는 연 30,000원) `[Assumption]` |
| 무료로 열어두는 것 | **보여주기 · 나누기 · 돌아보기 전부** — 제품의 핵심은 무료여야 쓰인다 |
| 유료가 여는 것 | 목표 여러 개 · 자녀 2명 이상 · 지난 기록 열람 `[미확정]` |
| 결제·환불 | **앱스토어 전담** ([ops-autonomy D2](../04-product/ops-autonomy.md)) |

**무엇을 유료로 할지가 아직 안 정해졌다.** POC에서 어떤 기능에 요구가 붙는지 보고 정한다. 지금 정하면 근거 없이 정하는 것이다.

### 수단 3. 소액 후원 — 보조

월 60만원은 후원으로도 닿을 수 있는 금액이다. 다만 **결제·영수증·문의가 붙으므로** 앱스토어 밖 후원은 조건 3(자율 운영)을 해친다. **순위를 낮춘다.**

## 4. 도달 경로 (G4 조건 2)

```
POC 종료                크레딧 확보($5,000)        유료 출시           유지 배수 1.0
   │                          │                      │                    │
   ├──── 0~12개월 ────────────┤                      │                    │
   │     크레딧으로 운영         ├──── 12~18개월 ──────┤                    │
   │     사용자 확보에 집중       │    무료로 사용자 축적   ├──── 18~24개월 ────┤
   │                          │                      │   유료 전환 0.24%    │
   │                          │                      │   = 235명 달성       │
```

| 시점 | 필요한 것 | 근거 |
|---|---|---|
| 0~12개월 | 크레딧 확보, 무료 운영 | 수단 1 |
| 12~18개월 | 유료 기능 정의 (POC 데이터 기반) | 수단 2 |
| 18~24개월 | **유료 사용자 235명** | 전환 0.24%는 통상 하한의 1/4 |

**전제:** 18~24개월 시점에 활성 10만 명이 있어야 한다. 그게 [acquisition-math.md](../01-discovery/acquisition-math.md)가 다루는 문제이고, **이 모델에서 가장 불확실한 항목**이다.

## 5. 판정

| 항목 | 상태 |
|---|---|
| RPU 수단 2개 이상 | **✅** 크레딧 + 인앱 구독 (후원은 보조) |
| 각 수단에 비교 사례 | **✅** 해외 5개 제품 월 $4~10 실재 |
| 유지 배수 1.0 경로가 숫자로 | **✅** 235명 / 전환 0.24% / 18~24개월 |
| 크레딧 의존 시 소진일 | **✅** POC + 12~24개월, 6개월 전 경보 |

**G4 조건 2: 충족.** 다만 분모(활성 10만)가 서지 않으면 이 표 전체가 무의미하다.
