## Phase 0 — 종이로 하는 보여주기 (2주)

앱을 만들지 않는다. **A4 한 장과 계산표로 「보여주기」를 사람이 돌린다.**

### 참가 키트 (인쇄물)

| 항목 | 내용 |
|---|---|
| **목표 카드** | 아이가 고른 물건 사진을 인쇄해 붙인다. **모은 만큼 색칠**하는 칸이 있다 — 사진 진행바의 종이판 |
| **금액→주 계산표** | *"500원 = 그대로 3주 / 1,500원 = 3주 / 2,000원 = 4주 / 4,000원 = 5주"*. 슬라이더의 종이판 |
| 지갑 두 칸 도안 | A4 한 장 |
| 주간 기록지 | 「샀어요」에 해당. 날짜·금액·(선택)이름 세 칸뿐 |

### 운영

| 언제 | 무엇을 |
|---|---|
| 월요일 | 운영자가 메시지로 알린다. 부모가 용돈을 주고 아이가 두 칸에 나눈다 |
| **아이가 조를 때** | **부모가 목표 카드와 계산표를 보여준다.** 아이가 정한다. 샀으면 기록지에 한 줄 |
| 토요일 | 운영자가 질문 한 줄을 보낸다. 부모가 아이와 이야기하고 기록지 사진을 보낸다 |

### 측정

| 지표 | 무엇을 말하나 | 통과선 |
|---|---|---|
| **4주 지속률** | A1 | **50% 이상** (10~15가구 중) |
| **보여주기 사용 빈도** | **A3′ — 이 제품의 존재 이유** | **주 2회 이상**인 가구가 절반 이상 |
| 아이 반응 (부모 서술) | **A2′ — 제3자 단서가 작동하는가** | 정성 관찰. "아이가 화면을 보고 생각을 바꾼 적이 있나" |
| 사기로 한 비율 | A5 — 보여준 뒤에도 사는가 | 숫자보다 **0%도 100%도 아닌지** |
| 목표 카드 색칠 여부 | A4 — 진행 표현이 읽히는가 | 아이가 스스로 색칠하는가 |
| 지갑 준비율 | 온보딩 첫 관문 | **60% 이상** |

### 종료 조건

- 4주 지속률 **30% 미만** → **종료.** 앱을 만들어도 같은 사람이 같은 이유로 빠진다
- **보여주기 사용이 주 1회 미만** → **설계를 다시 본다.** 조를 때 폰을 꺼내지 않는다면 제품의 전제가 틀린 것이다
- 지갑 준비율 40% 미만 → 실물 요구를 재설계하고 Phase 0 재실행

> **Phase 0의 지속률은 과대평가된다.** 사람이 직접 챙기고 참가자가 지인일 가능성이 높다. 그래서 통과선을 50%로 높게 잡았다.
> **모집 경로(맘카페·지인·커뮤니티)별로 몇 명이 왔는지 기록한다** — G2 조건 2(초기 시드 경로)의 첫 데이터다.

### 컷 옵션 — 버퍼가 부족할 때

| 자를 것 | 회수 | 대가 |
|---|---:|---|
| **홈을 「보여주기」에 통합** | **0.5** | 앱을 열면 보여주기 화면이 뜬다. 슬라이더가 0원이면 「샀어요」가 비활성. **제품적으로도 타당하다 — 앱의 주 용도가 보여주기다** |
| 사진 업로드를 사진첩 전용으로 (카메라 통합 생략) | 0.3 | 사용성 소폭 저하 |
| 잔액 보정을 돌아보기에서 제거 | 0.2 | 정확도 저하. A1 검증에는 무관 |

> **홈 통합을 우선 검토한다.** 버퍼가 0.8주로 늘고 화면이 4개가 된다.

### 기술 결정 (원가 설계와 일치)

- 인증·DB: 서버리스 Postgres 또는 BaaS 무료 티어
- 알림: FCM
- **생성형 모델 호출 없음.** 주간 요약도 규칙 기반 템플릿
- **목표 사진은 클라이언트에서 리사이즈 후 업로드** (긴 변 800px, ~150KB). 서버 이미지 처리 없음 → [unit-cost.md](../05-financial/unit-cost.md) 갱신 필요

## G3 통과 조건 (v2)

1. Phase 0 4주 지속률 **50% 이상** 이고 **보여주기 주 2회 이상 가구가 절반 이상** → Phase 1 착수
2. 12주 안에 1인으로 Phase 2까지. 초과 시 사유와 남은 범위를 문서에
3. **실측 온보딩 통과율 × M1 활성률이 12% 이상** — 미달이면 필요 다운로드가 카테고리 천장을 넘으므로 **종료**
4. 실측 CPU_월이 추정(6원)의 2배 이내
5. 실측 운영 부하를 10만 명으로 외삽해 주 1.5시간 이하
6. POC 사용자 인터뷰 5건 이상(**이탈자 2건 포함**). 반증된 가정이 있으면 브리프 갱신

> 인터뷰는 POC **뒤에** 한다. 쓸 물건이 없는 상태의 인터뷰는 의견을 모으지만, 써 본 사람의 인터뷰는 행동을 확인한다.
