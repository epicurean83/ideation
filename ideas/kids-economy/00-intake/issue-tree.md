# Issue Tree — 초등생 경제 관념 형성

작성일: 2026-09-16 · 단계: S0 · 트리 유형: **How** (목표가 고정돼 있고, 수단 후보를 갈라야 함)

## 0. 목표를 먼저 조작적으로 정의한다

"경제 관념을 심어준다"는 측정 불가능하다. 근거([01-discovery/evidence-base.md](../01-discovery/evidence-base.md) E2)가 지식과 행동의 효과 크기를 5배 차이로 갈라놓으므로, 목표를 행동으로 고정한다.

> **목표:** 만 6~12세 아동이 **자기 돈으로 하는 반복 결정**에서 (a) 쓰기 전에 멈추고, (b) 대안과 비교하고, (c) 목표를 위해 미루는 행동을 보인다.

지식 점수는 목표가 아니라 부산물이다. 이 정의가 아래 모든 가지의 채점 기준이 된다.

## 1. How 트리

```
HOW: 만 6~12세 아동에게 위 세 행동(멈춤·비교·미룸)을 어떻게 반복시킬 것인가?

├── 1. 학교 — 교과·수업 안에서 반복시킨다
│   ├── 1.1 교육과정 성취기준 자체를 바꾼다            [불가: 통제 밖]
│   ├── 1.2 범교과 학습 주제 시간에 넣는다              [기존: 한은 출강, 금감원 표준안이 이미 점유]
│   └── 1.3 교실 전체를 경제로 운영한다 (My Classroom Economy형)
│                                                   [근거 有: 저비용·저부담·강의식과 동등한 지식 향상]
│
├── 2. 가정 — 부모-자녀의 돈 대화를 루틴으로 만든다
│   ├── 2.1 용돈 지급 구조를 설계한다 (집안일 분리, 정기 지급)   [83.8%가 이미 지급 중 — 구조만 없음]
│   ├── 2.2 지출 결정 시점에 개입한다 (사기 전 멈춤·비교)       [부모 고민 1위 = 충동구매 41.2%]
│   └── 2.3 회고 루틴을 만든다 (월 1회 용돈 결산 대화)        [E4: 어른이 대화를 끌 때만 효과 확인됨]
│
├── 3. 금융 인프라 — 실제 돈이 움직이는 계좌·카드에 학습을 붙인다
│   ├── 3.1 아동 전용 카드·지갑을 제공한다                [선점됨: 토스 유스(만 7세~)가 사실상 표준]
│   ├── 3.2 기존 카드 위에 규칙 레이어를 얹는다 (한도·승인·목표) [퍼핀·아이부자가 부분 점유]
│   └── 3.3 저축 목표를 금융상품으로 만든다               [은행 CSR·적금 상품이 이미 무료 공급]
│
└── 4. 콘텐츠 — 지식과 이야기로 접근한다
    ├── 4.1 커리큘럼·교재                              [공공 무료: KDI, 경제배움e+, 금감원 표준안]
    ├── 4.2 게임·앱 (게이미피케이션)                      [E3: 지식 효과는 강의식과 동등, 우위는 지속뿐]
    └── 4.3 영상·캐릭터 IP                              [E1: 명시적 금융 지식 전달은 행동을 안 바꿈]
```

## 2. MECE 점검

- **중복 검사:** 1(학교)·2(가정)·3(인프라)·4(콘텐츠)는 **누가 반복을 강제하는가**로 갈랐다. 교사 / 부모 / 시스템 / 자기동기. 한 사실이 두 가지에 동시에 속하지 않는다. 단 3.2와 2.1은 경계가 붙어 있다 — "규칙을 시스템이 강제하나, 부모가 말로 강제하나"로 구분한다.
- **커버리지 검사:** 빠진 주체는 **또래**(친구끼리의 교환·거래)와 **시장 자체**(실제 판매 경험, 플리마켓·창업체험). 후자는 1.3에 부분 포함되나 독립 가지로 나올 수 있다. 현재는 **의도적 보류**로 표시한다.
- 레벨 2도 같은 기준으로 갈랐다.

## 3. 트리에서 즉시 죽는 가지

| 가지 | 사유 |
|---|---|
| 1.1 교육과정 변경 | 통제 밖. 2022 개정 교육과정은 이미 고시됨 |
| 1.2 범교과 시간 | 한국은행이 초4~고3에 직원을 직접 출강시킨다. 무료 + 국가 브랜드와 정면 경쟁 |
| 3.1 아동 카드 | 만 7세부터 토스 유스가 표준. 라이선스·마케팅 비용 정면 부담 |
| 4.1 커리큘럼·교재 | KDI·기재부·금감원이 전부 무료 배포 |
| 4.3 영상·IP | E1이 직접 반박 — 명시적 금융 지식은 어린 아이 행동을 안 바꿈 |

## 4. 살아남은 가지

| 가지 | 남은 이유 | 다음 확인 |
|---|---|---|
| **2.2 지출 결정 시점 개입** | 부모가 스스로 지목한 통증 1위(충동구매 41.2%)와 직접 일치. 공공·핀테크 모두 여기를 안 건드림 | 부모가 이걸 위해 돈을 내는가 |
| **2.3 회고 루틴** | E4가 효과를 확인한 유일한 조건(어른이 대화를 끄는 경우) | 루틴이 4주 이상 유지되는가 |
| **1.3 교실 경제** | 근거 있고 저비용. 단 지불 주체가 학교(B2G/B2S)로 바뀜 | 학교 예산이 붙는 항목인가 |
| **3.2 규칙 레이어** | 퍼핀·아이부자가 점유했으나 "게이미피케이션 = 지속"이라는 전제가 국내에서 실증됐는지 불명 | 실제 리텐션 |

**Output:** 수단 후보 4개(2.2, 2.3, 1.3, 3.2). 순위는 S1 `prioritize`에서 매긴다. 그 전에 **지불 주체**를 먼저 잘라야 한다 — 2.2·2.3은 부모, 1.3은 학교, 3.2는 부모지만 이미 무료 대안이 있다.

> **경고:** 이 트리는 구조이지 증거가 아니다. "살아남은 가지"는 아직 검증된 기회가 아니라 **아직 반증되지 않은 가설**이다.
