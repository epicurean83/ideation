# The Mom Test 기반 POC 사용자 인터뷰 가이드

## 1. 인터뷰 원칙 (The Mom Test Protocol)
1. **아이디어에 대해 묻지 않는다**: "이런 기능 있으면 쓰실래요?" (X) $\rightarrow$ 미래의 의견은 거짓말이다.
2. **과거의 실제 행동을 묻는다**: "지난주에 책 읽으면서 좋은 문장을 봤을 때 실제로 어떻게 하셨나요?" (O)
3. **말을 적게 하고 침묵을 지킨다**: 사용자가 멈칫거리거나 불편해하는 순간을 관찰한다.
4. **이탈자 인터뷰 필수**: 1회 사용 후 재방문하지 않은 사용자 3명 이상 인터뷰.

---

## 2. 질문 스크립트

### Warm-up (평소 독서 및 공유 습관)
* "가장 최근에 책을 읽으셨던 게 언제인가요? 어떤 책이었나요?"
* "책을 읽다가 마음에 와닿는 문장이 나오면 보통 그 순간에 어떤 행동을 하세요?" (밑줄, 사진 촬영, 메모 등)
* "그 문장을 다른 사람에게 보여주거나 SNS에 올린 적이 있으신가요? 그때 어떤 앱을 써서 어떻게 올리셨나요?"

### POC 실사용 경험 검증 (잔존자 대상)
* "소셜 마진으로 처음 카드를 만들어 인스타/스레드에 올렸을 때의 과정에서 가장 귀찮거나 헷갈렸던 점은 무엇이었나요?"
* "다른 사람이 내가 올린 문장에 남긴 마진(주석)을 처음 봤을 때 어떤 기분이 드셨나요?"
* "솔직히 말씀해 주세요. 이 서비스가 내일 당장 사라진다면, 대신 어떤 도구를 쓰실 것 같나요?"

### 이탈자 심층 탐색 (Churned User 대상)
* "처음에 카드를 만드시고 나서 그 이후로는 앱을 켜지 않으셨는데, 가장 큰 이유가 무엇이었나요?"
* "문장을 기록하거나 남들의 생각을 보는 과정에서 어떤 점이 번거롭거나 부담스러우셨나요?"
