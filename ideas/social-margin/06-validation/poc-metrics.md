# 실사용 계측 설계서 (POC Metrics Spec - S3)

## 1. 실측 대상 핵심 지표 및 합격 기준 (G3 Gate)

| 지표명 | 측정 방식 및 산식 | G3 합격 기준선 | 위험 신호 (Red Flag) |
|---|---|:---:|:---:|
| **바이럴 계수 ($K$)** | (초대/공유로 유입된 신규 방문자) $\div$ (기존 활성 사용자) | **$K \ge 1.0$** | $K < 0.5$ (오가닉 성장 불가) |
| **카드 공유율** | (SNS 내보내기 버튼 클릭 수) $\div$ (카드 생성 수) | **$\ge 40\%$** | $< 15\%$ (디자인 매력 부족) |
| **W4 리텐션** | 4주 차 재방문율 (첫 방문 후 28일 뒤 주간 활성 유지율) | **$\ge 25\%$** | $< 10\%$ (일회성 툴로 전락) |
| **실측 CPU_월** | (한 달간 발생한 Cloudflare + Supabase 총 비용) $\div$ (실제 MAU) | **$\le 10\text{원}$ (녹색)** | $> 30\text{원}$ (원가 구조 결함) |
| **실측 운영 부하** | 주당 버그 수정, 모더레이션, CS에 실제 투입한 시간 (100명 기준) | **주 $\le 1.0$시간** | 주 $> 5.0$시간 (선형 인건비 발생) |

---

## 2. 계측 인프라 구성
* **이벤트 로깅**: PostHog 또는 Cloudflare Web Analytics (쿠키 프리 경량 트래킹).
* **트래킹 이벤트 목록**:
  * `quote_captured`: OCR 또는 텍스트 입력으로 문장 생성
  * `card_exported`: 인스타/스레드 규격 카드 다운로드 또는 클립보드 복사
  * `margin_created`: 타인의 문장에 소셜 마진(주석) 작성
  * `silent_room_completed`: 뽀모도로 무음 독서 25분 완주
  * `deeplink_landed`: SNS 카드 워터마크 링크를 통한 신규 유입
