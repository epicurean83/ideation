# 원가 모델 (Unit Cost / CPU_월)

## 1. 기본 원칙
* 서버 사이드 생성형 LLM(OpenAI/Claude API) 호출 전면 금지.
* 브라우저 온디바이스 연산(Wasm/Canvas) 및 Edge 캐시 극대화.
* **합격선 기준**: CPU_월 ≤ 30원 (녹색).

## 2. 사용자 규모별 월 원가 곡선 (1만 / 10만 / 100만 MAU)

| 원가 구성 요소 | 1만 MAU | 10만 MAU | 100만 MAU | 1인당 월 원가 (100만 기준) |
|---|:---:|:---:|:---:|:---:|
| **Edge 컴퓨팅 (Cloudflare/Supabase)** | 0원 (무료티어) | ~7만 원 ($50) | ~140만 원 ($1,000) | **1.4원** |
| **스토리지/CDN (Cloudflare R2)** | 0원 (무료티어) | ~3만 원 ($20) | ~42만 원 ($300) | **0.4원** |
| **OCR & 타이포 카드 렌더링** | **0원 (온디바이스)** | **0원 (온디바이스)** | **0원 (온디바이스)** | **0.0원** |

## 3. 원가 절감 메커니즘
1. **OCR / 렌더링**: Tesseract.js 및 HTML5 Canvas를 브라우저에서 실행하여 서버 CPU 부하 제로화.
2. **트래픽 비용 제로화**: Egress(아웃바운드 트래픽) 무료 정책을 제공하는 Cloudflare R2 및 Edge CDN 활용.
3. **서지 데이터 영구 캐싱**: 한 번 검색된 도서의 메타데이터는 Edge KV에 영구 캐싱하여 외부 API 호출 수 최소화.
