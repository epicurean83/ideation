# 블루오션 전략: ERRC 그리드 & 전략 캔버스

## 1. ERRC 그리드 (Four Actions Framework)

| 제거 (Eliminate) - 원가/피로 제거 | 줄이기 (Reduce) - 운영 부하/장벽 완화 |
|---|---|
| • **서버 단 생성형 LLM 호출** (온디바이스로 원가 0원화)<br>• **강제 독후감 제출 의무** (문장 1개 기록으로 대체)<br>• **실시간 화상/음성 대화** (사회적 에너지 소모 제거)<br>• **수동 모더레이션/검수 인력** (규칙 기반 자율화) | • **포스팅 작성 공수** (카메라 촬영 즉시 카드 변환)<br>• **모임 참여 비용** (시즌 30만 원 → 무료/초저가)<br>• **서지 데이터베이스 API 호출** (Edge KV 영구 캐싱)<br>• **1인당 운영 개입 시간** (100만 기준 주 9.5시간 이하) |
| **높이기 (Raise) - 텍스트힙 가치 극대화** | **창조하기 (Create) - 미개척 시장 개척** |
| • **타이포그래피 및 카드 비주얼 완성도**<br>• **문장 단위 지적 사유의 밀도**<br>• **SNS(인스타/스레드) 바이럴 공유 편의성**<br>• **무드(Vibe) 기반의 감성 탐색 경험** | • **Social Margin Notes** (문장별 비동기 소셜 주석)<br>• **Silent Reading Room** (디지털 텍스트 바)<br>• **Text Taste DNA** (개인 독서 취향 지적 브랜딩 리포트)<br>• **도서 구매 딥링크 플라이휠** |
