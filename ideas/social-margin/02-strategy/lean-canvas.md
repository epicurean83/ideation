# 소셜 마진 (Social Margin) 린 캔버스

| 구분 | 내용 |
|---|---|
| **1. 문제 (Problem)** | • 독서 기록과 SNS 공유 과정의 극심한 파편화 및 디자인 피로도<br>• 기존 오프라인 모임의 높은 비용(20~40만 원)과 강제성 부담<br>• 기존 SNS의 지적 대화 맥락 부재 및 타임라인 휘발성 |
| **2. 고객 세그먼트 (Customer Segments)** | • **Early Adopter**: 인스타 #북스타그램 / 스레드에서 글귀를 소비·공유하는 2030 독서가<br>• **Mainstream**: 숏폼 피로감으로 책/텍스트를 다시 읽기 시작한 '텍스트힙' 입문자 |
| **3. 고유 가치 제안 (UVP)** | **"문장으로 나를 표현하고, 마진(책의 여백)에서 지적으로 연결되는 텍스트힙 공간"** |
| **4. 솔루션 (Solution)** | • **Aesthetic Typo-Card**: 1초 완성 감성 타이포그래피 카드 렌더링<br>• **Social Margin Notes**: 문장 밑줄 아래 남기는 비동기 포스트잇 소통<br>• **Silent Reading Room**: 마이크/카메라 없는 무압박 뽀모도로 공존 독서 |
| **5. 채널 (Channels)** | • 유저 생성 타이포 카드의 인스타그램 스토리 / 스레드 바이럴 공유 (워터마크/딥링크)<br>• 도서/문장 검색엔진 최적화 (SEO)<br>• 독립서점 / 문학 출판사 콜라보레이션 |
| **6. 유지비/수익원 (Revenue Streams)** | • **RPU_월 ~47.0원**<br>• 독점 폰트/아티스틱 템플릿 패스 (월 2,900원, 전환율 1%)<br>• 도서 구매 제휴 링크 (어필리에이트 3%, 전환율 2%)<br>• 출판사 셀프 신간 문장 챌린지 스폰서십 (월 3건) |
| **7. 원가 구조 (Cost Structure)** | • **CPU_월 ~5.2원** (100만 MAU 기준 월 총 인프라비 ~320만 원)<br>• 클라이언트 온디바이스 OCR/렌더링 (서버 연산비 0원)<br>• Cloudflare Workers + Supabase Edge 캐싱 + R2 스토리지 |
| **8. 핵심 지표 (Key Metrics)** | • **북마크/문장 카드 생성 수 & SNS 공유율** (바이럴 계수 K > 1.2)<br>• **W4(4주차) 리텐션** (목표 ≥ 25%)<br>• **월 유지 배수** (RPU ÷ CPU ≥ 1.0 유지) |
| **9. 경쟁 우위/해자 (Unfair Advantage)** | • 유저들이 직접 밑줄 긋고 주석을 남긴 **'문장 단위 소셜 마진 데이터'**의 네트워크 효과<br>• 감정/무드(Vibe) 기반 독서 취향 그래프 |
