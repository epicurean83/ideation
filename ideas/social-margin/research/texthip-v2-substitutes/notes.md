# 텍스트힙 v2 — 대체재·경쟁 조사 노트

조사일: 2026-09-22. WebSearch 15건 사용(한도 15건 소진, 추가 검색 안 함). WebFetch 0건(검색 스니펫으로 충분히 답변 가능해 페이지 원문 fetch는 생략함 — 추가 검증 필요 시 fetch 권장).

## 1. 무료 대체재가 "페이지 사진 꾸미기"를 덮는가

### 1-1. 인스타그램 스토리 편집기
- 드로잉 도구에 **형광펜(highlighter)**, 펜, 네온, 지우개, 초크 스타일 포함. 텍스트 정렬·크기·색상·배경 커스터마이즈 가능. "컷아웃 스티커"(사진에서 피사체만 자동 스티커화), "Add Yours 템플릿" 기능 존재.
  - 출처: [고구마팜 블로그 — Z세대가 인스타그램 스토리를 꾸미는 방법](https://gogumafarm.kr/z%EC%84%B8%EB%8C%80%EA%B0%80-%EC%9D%B8%EC%8A%A4%ED%83%80%EA%B7%B8%EB%9E%A8-%EC%8A%A4%ED%86%A0%EB%A6%AC%EB%A5%BC-%EA%BE%B8%EB%AF%B8%EB%8A%94-%EB%B0%A9%EB%B2%95-%EB%8B%B5%EC%9D%80-%EC%8A%A4%ED%8B%B0/) (날짜 미상, Medium, 비공식 블로그) / [Adobe 인스타 스토리 스티커 가이드](https://www.adobe.com/kr/creativecloud/roc/blog/design/instagram-story-sticker.html)
  - 판정: 종이 페이지 사진 위에 형광펜으로 밑줄을 긋고 텍스트 스티커를 붙이는 것은 **인스타그램 네이티브 기능만으로 이미 가능**. High confidence (기능 존재는 일반적으로 알려진 사실, 검색으로 재확인).

### 1-2. 글그램
- "사진에 글쓰기" 앱. 배경 사진 위에 감성 글귀·손글씨체 폰트를 얹는 용도. **사용자가 찍은 종이 페이지 사진 위에 얹는 용도가 아니라, 앱이 제공하는 배경 사진 + 텍스트 조합이 핵심.** 페이지 사진 밑줄 기능은 확인 안 됨.
  - 출처: [Google Play — 글그램](https://play.google.com/store/apps/details?id=com.withwho.gulgram) (날짜 미상, Low~Medium confidence, 다운로드 수치 미확인)

### 1-3. "책 사진 밑줄" 전용 앱 (영어권)
- **Highlighted: Book Highlights** — 카메라로 페이지를 찍어 텍스트를 선택·저장. 책·페이지·노트·태그 기록, Kindle/CSV 임포트, "beautiful quote cards" 공유 기능. **150,000+ 사용자**(앱 내 표기, 공식 다운로드 수치는 아님).
  - 출처: [App Store — Highlighted](https://apps.apple.com/us/app/highlighted-image-to-text/id1480216009), [Ebook Friendly 소개 기사](https://ebookfriendly.com/highlighted-book-scanner-app-ipad-iphone/) — Medium confidence, 날짜 미상(기사는 앱 초기 출시 시점으로 추정)
- **Excerpt - The Book Highlighter** — 카메라로 페이지 촬영, 하이라이터 색상 커스터마이즈, 노트·챕터 태깅, 공유·내보내기. 규모 미확인.
  - 출처: [App Store — Excerpt](https://apps.apple.com/us/app/excerpt-the-book-highlighter/id1447907126) — Low confidence(다운로드 수치 없음)
- **판정:** 영어권에는 "카메라로 페이지 찍어 하이라이트+quote card 공유"를 정확히 하는 전용 앱이 **이미 존재**(Highlighted, Excerpt). 둘 다 개인 기록·quote card 생성에 집중하고, **소셜 피드·팔로우·DM·같은 책 독자 채널 같은 커뮤니티 레이어는 없음**(검색 범위 내 확인 안 됨 — 이 부분이 빈틈일 가능성).
- 한국어 앱스토어에서 "북스타그램 꾸미기" 전용 앱은 검색되지 않음(리드로그가 OCR 기반 문장 카드 생성으로 가장 근접 — 아래 2절 참조). **못 찾음 — 국내에 전용 앱이 거의 없거나 인지도가 낮다는 신호로 해석 가능, 확언은 안 함.**

### 1-4. 종합 판정
- 무료 대체재(인스타 스토리)가 "사진 찍고 형광펜 긋고 스티커 붙이기"라는 **개별 동작**은 이미 완전히 덮는다. 기술적 진입장벽 없음.
- 영어권에는 이 동작을 책 전용으로 특화한 앱(Highlighted, Excerpt)도 이미 있으나 **소셜 피드/커뮤니티가 약함**.
- 국내에는 리드로그(OCR 문장 카드, 아래 참조)가 가장 근접하지만 예쁜 꾸미기보다 아카이빙에 방점.
- **남는 빈틈:** "예쁘게 꾸민 페이지 사진" + "같은 책 읽는 사람과의 소셜 연결(피드·구절 답글 잇기·같은 책 채널·DM)"을 **한 앱 안에서 결합**한 사례는 조사 범위 내에서 발견되지 않음. 다만 이것이 진짜 빈틈인지, 아니면 "안 되는 이유가 있어서 아무도 안 만든 것"인지는 이 조사로는 판별 불가 — 사용자 인터뷰/원가 검증 필요.

## 4. 텍스트힙 트렌드 — 페이지 사진+밑줄 사례

- "인스타그램에 '책스타그램'·'북스타그램'을 검색하면 좋아하는 책 구절이 나온 페이지를 찍은 사진이나 필사 게시물"이 텍스트힙의 대표 소비 형태로 여러 매체가 공통 언급.
  - 출처: [Cheil 매거진](https://magazine.cheil.com/56133), [토스뱅크 아티클](https://www.tossbank.com/articles/texthip), [KB금융 생각](https://kbthink.com/main/living-finance/consumption-life/mz-consumption/text-hip.html) — 모두 브랜드 콘텐츠 마케팅 성격, Medium confidence(트렌드 서술은 일치하나 정량 데이터는 없음)
- 픽플리(데이터 기반 블로그)는 "텍스트힙, 정말 트렌드일까"라는 제목으로 실제 소비 데이터와 담론의 괴리를 다루는 것으로 보임(본문 미확인, 제목만 확보). **회의적 관점 존재 — 후속 확인 권장.**
  - 출처: [픽플리 블로그](https://pickply.com/blog/books-and-text-hip-trend-consumer-experience) — Low(본문 미열람)
- **페이지 사진+형광펜 밑줄을 특정해서 다룬 브랜드 캠페인 사례**는 이번 검색에서 명시적으로 확인되지 않음. 트렌드 기사들은 "구절 찍은 사진·필사"를 뭉뚱그려 언급할 뿐, 밑줄/스티커 꾸미기를 별도로 조명한 사례는 못 찾음.

## 5. 운영·규제 리스크

- **정보통신망법**: "대규모 정보통신서비스 제공자"에 불법정보·허위조작정보 신고 접수·통지·자율 운영정책 수립 의무를 부과하는 조항이 2025.12 국회 본회의 통과. 조문상 의무 대상이 "대규모" 사업자로 규정되어 있어 소규모 스타트업 앱에 동일 수준으로 적용되는지는 이번 검색으로 명확히 확인 안 됨(법 시행령·기준 규모 정의를 별도 확인 필요).
  - 출처: [글로벌이코노믹](https://www.g-enews.com/article/General-News/2025/12/202512241350197569edf69f862c_1) — Medium(법안 통과 보도, 소규모 사업자 적용 여부는 불명확)
- **청소년보호/개인정보**: 만 14세 미만 가입 시 법정대리인 동의 절차 필수(개인정보보호법 계열). DM·메시지 관련해서는 Meta·카카오 등 대형 플랫폼이 "팔로우하지 않은 사람의 DM 기본 차단", "패밀리 계정 보호자 관리" 등 자체 정책으로 대응 중 — 이는 대형사 사례이며, 소규모 앱이 동일 인프라를 갖췄는지는 확인 안 됨(추정: 소규모 앱은 이런 안전장치 없이 DM/채널 기능을 열면 규제·평판 리스크가 상대적으로 큼).
  - 출처: [카카오톡 미성년자 보호조치](https://talksafety.kakao.com/policy/usersafety/protectminor), [Meta 뉴스룸](https://about.fb.com/ko/news/2024/01/introducing-stricter-message-settings-for-teens-on-instagram-and-facebook/) — High(공식 정책 페이지)
- **소규모 앱이 실제로 겪은 사례**: 이번 검색 범위에서 국내 소규모 소셜/독서 앱이 신고처리·미성년자 보호 관련 제재를 받은 구체적 사례는 찾지 못함. 못 찾았다는 사실 자체를 기록함 — 추가 조사 필요.
