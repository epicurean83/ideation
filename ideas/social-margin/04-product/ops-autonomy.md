# 자율 운영 설계서 (Ops Autonomy - 조건 3 검증)

## 1. 운영 자동화 원칙
100만 MAU가 달성되어도 **1인 운영자의 주당 개입 시간을 15시간 이내**로 완벽히 격리한다.

## 2. 5대 핵심 영역 자동화 체크리스트

| 운영 영역 | 자동화 설계 및 시스템 | 100만 MAU 시점 대안 (예외 처리) | 주당 개입 시간 |
|---|---|---|:---:|
| **1. 가입 / 인증 / 결제 / 환불** | • 소셜 간편 로그인 (카카오/Apple/Google)<br>• 토스페이먼츠 웹훅 기반 자동 승인<br>• 결제 7일 내 미사용 시 **100% 원클릭 셀프 환불** | 환불/결제 오류 티켓 발생 시 자동 환불 큐 처리 | **1.0시간** |
| **2. 콘텐츠 모더레이션 & 어뷰징** | • 비속어/도배 실시간 정규식 사전 차단<br>• **3회 이상 유저 신고 시 자동 블라인드(Shadowban)**<br>• 신고 신뢰도 가중치 알고리즘 적용 | 사용자의 '블라인드 이의제기' 큐만 주 2회 배치 검토 | **3.5시간** |
| **3. 인프라 / 장애 대응** | • Cloudflare Edge 자동 페일오버<br>• Sentry 크리티컬 에러 발생 시 텔레그램 봇 푸시<br>• 일일 DB 자동 스냅샷 및 무중단 배포 (GitHub Actions) | 긴급 장애 알림 수신 시 원클릭 롤백 스크립트 실행 | **1.5시간** |
| **4. 고객 문의 (CS)** | • Notion/GitBook 기반 반응형 인터랙티브 FAQ<br>• 1차 룰베이스 챗봇 답변으로 95% 해소 | 미해결 1:1 이메일 문의만 주 2회 모아서 답변 | **1.5시간** |
| **5. 스폰서십 & 제휴 관리** | • 출판사용 셀프 슬롯 예약 및 결제 폼<br>• 가이드라인 위반 여부 체크리스트 셀프 서명 | 주 1회 등록된 스폰서 문장 승인 버튼 클릭 (10분) | **2.0시간** |
| **총 주당 운영 부하** | - | - | **약 9.5시간** |
